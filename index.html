Proyectos y Experiencia

Hardware & Software

Desarrollador de Software | Instituto Tecnológico de Tláhuac

Desarrollo de software médico y biométrico integrado con hardware.

  • Aseguré reversibilidad total y fidelidad diagnóstica en imágenes médicas.
  • Optimicé la seguridad reduciendo errores de autenticación.
  • Programé e integré la lógica para conectar un sensor de huella dactilar físico en MATLAB.
  • Co-redacté un artículo científico y expuse resultados en el congreso internacional CITCA.

Este proyecto involucró el procesamiento de imágenes médicas con técnicas de compresión sin pérdida, asegurando que las imágenes pudieran reconstruirse fielmente para diagnóstico. Se implementó un sistema biométrico con sensor de huella dactilar para control de acceso al sistema, demostrando la integración exitosa entre hardware y software médico.

E-commerce Backend | Fyndr

Plataforma de comercio electrónico para contratación de servicios y oficios técnicos.

  • Diseñé e implementé la arquitectura del backend utilizando Java y Spring Boot.
  • Desarrollé APIs REST eficientes para gestión de usuarios y transacciones.
  • Colaboré activamente en un equipo de 6 personas bajo metodología SCRUM (dailies).
  • Integré endpoints con frontend en Vite garantizando alta velocidad de datos.

Arquitectura MVC con Spring Boot, implementando patrones de diseño como Repository y Service Layer. Se diseñaron endpoints RESTful con documentación Swagger, autenticación JWT, y manejo de excepciones centralizado. La base de datos relacional fue diseñada con MySQL, optimizando queries para alto rendimiento.
